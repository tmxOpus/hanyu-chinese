# Hànyǔ — китайский по словам

Сайт для изучения китайского: введите слово по-русски или иероглифами (или пиньинем) и получите
перевод, транскрипцию с цветовыми тонами и анимацию порядка черт каждого иероглифа.

## Запуск

Проект — статический сайт без сборки. Откройте папку в любом локальном сервере, например:

```bash
python3 -m http.server 8080
```

и перейдите на http://localhost:8080.

## Структура

- `index.html` — разметка и подключение библиотек (через CDN)
- `css/style.css` — стили, светлая и тёмная темы, адаптивная вёрстка
- `js/dictionary.js` — стартовый словарь: `[иероглифы, пиньинь, перевод]`
- `js/app.js` — поиск, карточка результата, анимация, история, тема

## Как работает поиск

1. Сначала ищем в `js/dictionary.js` (по иероглифам, русскому слову или пиньиню без тонов).
2. Если слова нет, а ввод на русском или иероглифами — запрос уходит в онлайн-переводчик
   [MyMemory](https://mymemory.translated.net/). Результат помечается как автоматический.
3. Пиньинь для слов вне словаря считается библиотекой [pinyin-pro](https://github.com/zh-lx/pinyin-pro).
4. Анимация порядка черт — [Hanzi Writer](https://hanziwriter.org) с данными из `hanzi-writer-data`.

## Расширение словаря

Добавьте строку в `js/dictionary.js`:

```js
["图书馆", "túshūguǎn", "библиотека"],
```

Пиньинь пишите с диакритикой и пробелами между слогами, перевод — через запятую или `;`.
Иероглифов в слове и слогов в пиньине должно быть поровну, тогда у каждого иероглифа появится
своя подпись с тоном.
