Политика конфиденциальности

Действует с 16 октября 2026 года

Этот документ объясняет, какие данные обрабатывает сайт Hànyǔ (далее — «сайт»), зачем это нужно и какие у вас есть возможности. Сайт — бесплатный учебный ресурс для изучения китайского языка.

1. Кто управляет сайтом

Сайт опубликован на платформе GitHub Pages. Владелец сайта — аккаунт tmxOpus на GitHub. Исходный код и обращения принимаются через раздел Issues репозитория github.com/tmxOpus/hanyu-chinese.

2. Какие данные обрабатываются

Сайт не требует регистрации, не просит имени, адреса, телефона или почты и не ведёт аккаунтов пользователей. Сайт не использует cookie, аналитику и рекламные трекеры.

  • Поисковые запросы по словарю. Обрабатываются только в вашем браузере. Никуда не отправляются.
  • Поисковые запросы вне словаря. Если слова нет в словаре, текст запроса отправляется в сервис онлайн-перевода MyMemory (см. раздел 4).
  • История поиска и прогресс в курсе (пройденные упражнения, результаты контрольных). Хранятся в локальном хранилище вашего браузера (localStorage). На сервер не передаются.
  • Технические данные запроса. При открытии любой страницы хостинг GitHub Pages и сервисы, которые загружают библиотеки и шрифты, получают IP-адрес, тип браузера и время запроса. Это стандартная работа интернета, которую сайт не контролирует.

3. Зачем и на каком основании

  • Чтобы показать перевод, пиньинь, анимацию иероглифов и страницы курса.
  • Чтобы сохранить ваш прогресс и историю поиска на вашем устройстве, если вы этого хотите.
  • Чтобы техническая инфраструктура работала безопасно и стабильно.

Владелец сайта не получает от вас никаких данных, кроме тех, что перечислены выше, и не продаёт их.

4. Кто ещё получает ваши запросы

  • MyMemory (api.mymemory.translated.net) — онлайн-перевод слов вне словаря. Получает текст запроса, IP-адрес и данные браузера. Его правила обработки данных определяет сам сервис: mymemory.translated.net.
  • GitHub — хостинг сайта. Заявление о конфиденциальности GitHub.
  • jsDelivr и unpkg — CDN, с которых загружаются библиотеки Hanzi Writer и pinyin-pro. Получают IP-адрес при загрузке. Сайты: jsdelivr.com, unpkg.com.
  • Google Fonts — загрузка шрифтов. Политика конфиденциальности Google.

Другим сторонам сайт не передаёт ничего. Сайт задаёт браузеру строгие правила: он может обращаться только к перечисленным адресам, а адрес текущей страницы в запросы к сторонним сервисам не передаётся.

5. Как долго хранятся данные

  • История поиска и прогресс хранятся в вашем браузере, пока вы их не удалите.
  • Владелец сайта не хранит ваши запросы, потому что они нигде не сохраняются на стороне сайта.
  • Журналы GitHub, CDN и MyMemory хранятся по их собственным правилам.

6. Как удалить свои данные

  • Историю и прогресс можно удалить, очистив данные сайта в настройках браузера: «Настройки → Конфиденциальность → Данные сайтов» и удалить запись для адреса сайта.
  • Данные у внешних сервисов удаляются через них самих по их инструкциям.

7. Ваши права

Вы можете попросить разъяснить, какие данные обрабатываются, или сообщить о неточности, написав через Issues репозитория (раздел 1). Мы ответим в разумный срок. Если вы живёте в стране, где законы о персональных данных дают дополнительные права (например, право на удаление или на перенос данных), эти права тоже действуют.

8. Безопасность

Сайт работает только по защищённому соединению (HTTPS). Загружаемые библиотеки проверяются по контрольным суммам (SRI). Политика безопасности браузера запрещает сайту обращаться к адресам, не перечисленным выше. Ни один способ защиты не даёт полной гарантии, поэтому не вводите в поиск личные данные.

9. Дети

Сайт ориентирован на изучение языка любыми пользователями, включая школьников. Сайт не собирает данные, по которым можно идентифицировать человека, поэтому отдельных мер для детей не требуется. Если вы родитель и хотите ограничить доступ ребёнка к внешним сервисам, перечисленным в разделе 4, сделать это можно через настройки браузера.

10. Изменения документа

Если правила изменятся, новая версия появится на этой странице с новой датой вступления в силу. Существенные изменения, влияющие на данные, будут отмечены в начале документа.
