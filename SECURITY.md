# Безопасность

## Что за сайт

Hànyǔ — статический сайт без серверной части, аккаунтов и базы данных. Пользовательские данные
нигде не хранятся, кроме истории поиска в `localStorage` вашего браузера, которая никуда не отправляется.

## Какие внешние сервисы используются

| Что | Куда уходит | Зачем |
| --- | --- | --- |
| Скрипты Hanzi Writer и pinyin-pro | cdn.jsdelivr.net (проверяются по SRI-хэшу) | анимация и пиньинь |
| Данные черт (запасной вариант) | cdn.jsdelivr.net, unpkg.com | только для иероглифов вне `js/strokes.js` |
| Шрифты | fonts.googleapis.com, fonts.gstatic.com | оформление |
| Онлайн-перевод | api.mymemory.translated.net | **текст запроса уходит сервису**, только если слова нет в словаре |

Запросы в онлайн-перевод отправляются без реферера (`referrerPolicy: no-referrer`) и обрываются через 8 секунд.

## Защита, которая уже есть

- **Content Security Policy** (мета-тег в `index.html`): скрипты, стили и сетевые запросы разрешены только с перечисленных адресов, `object-src` и `form-action` закрыты.
- **Subresource Integrity**: для скриптов с CDN указаны `sha384`-хэши, подменённый файл не выполнится.
- **Referrer-Policy**: адрес страницы не передаётся внешним сайтам в полном виде.
- **Ввод не вставляется как HTML**: весь пользовательский текст выводится через `textContent`, `innerHTML` не используется.
- **Ограничение ввода**: запрос обрезается до 100 символов, управляющие символы удаляются.

## Ограничения

- GitHub Pages не позволяет задавать HTTP-заголовки, поэтому нельзя запретить встраивание сайта в iframe (`frame-ancestors`) и включить `X-Frame-Options`. Для сайта без входа и платежей это низкий риск.
- Политика задана мета-тегом и действует только в браузере, который её поддерживает.

## Сообщить о проблеме

Если нашли уязвимость, не публикуйте её в открытом issue. Используйте приватное сообщение о
безопасности в GitHub: вкладка **Security → Report a vulnerability** в репозитории.
